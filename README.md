# Next.js Projects

A collection of independent Next.js applications, each organized in its own folder.

## Projects

| Project | Description | Directory |
| --- | --- | --- |
| **Campus Directory** | Browse student profiles, academic departments, and specializations. | [`campus-directory`](./campus-directory/) |
| **Orbit Docs** | Explore a responsive documentation portal with articles, guides, search, and theme switching. | [`orbit-docs`](./orbit-docs/) |

## Run a project

Each application has its own dependencies and README. For example, to run Orbit Docs:

```powershell
cd orbit-docs
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. To run Campus Directory instead, change into `campus-directory`.

Both projects require Node.js 20.9 or newer. See the project READMEs for features, routes, and additional commands:

- [Campus Directory README](./campus-directory/README.md)
- [Orbit Docs README](./orbit-docs/README.md)
